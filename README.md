# Smyle Dental, website redesign

Prototype pages for the smyledentist.com redesign, built on the design system
approved by the design team.

**Live review hub:** https://angel062388.github.io/smyle-redesign/

## What is in here

| File | Page |
|---|---|
| `index.html` | Review hub, links to every page as it is built |
| `cosmetic-dentistry-bakersfield.html` | Cosmetic Dentistry, Bakersfield |

## Important

These are **prototypes for review, not the live website**. Booking forms do not
submit and navigation links are inactive. The live site remains at
smyledentist.com.

Each page is a single self-contained HTML file with its images embedded, so any
page can be opened or shared on its own. That keeps the files large, around 2MB,
which is fine for review but is not how the pages will ship. On the real
WordPress build the images become normal cached image files.

## Design system

Built on the V3 direction:

- **Paper** `#FAF7F1`, **ink** `#1E1B16`, **brand yellow** `#FFD900`
- **Fraunces** for headings, **Nunito Sans** for everything else
- 1120px container, 92px section rhythm, pill buttons
